Open the CallBlocker ROOT folder in Android Studio.
Required:
- Gradle: 8.11.1 (defined in gradle/wrapper/gradle-wrapper.properties)
- Gradle JDK: 17
- Android Gradle Plugin: 8.9.1
- Kotlin: 2.1.20

If Android Studio asks which Gradle distribution to use, choose:
"gradle-wrapper.properties" / Wrapper.

APK:
Build -> Build App Bundle(s) / APK(s) -> Build APK(s)
Output: app/build/outputs/apk/debug/app-debug.apk
