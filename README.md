# CallBlocker

Android-приложение для локальной блокировки входящих звонков по номеру или тексту, который отображает системная звонилка.

## Возможности

- Блокирует вызовы по номеру и текстовым правилам.
- Завершает совпавшие вызовы через `TelecomManager.endCall()`.
- Не заменяет системное приложение «Телефон» и не нажимает кнопки звонилки через Accessibility.
- Включает диагностику разрешений и данных, полученных от Accessibility.

## Установка

1. Скачайте APK из раздела **Releases**.
2. Установите APK на устройство с Android 10 или новее.
3. Разрешите доступ к телефону и журналу вызовов.
4. В приложении включите блокировку и службу специальных возможностей.

## Важно

Работа с текстовыми правилами зависит от структуры экрана входящего вызова, которую предоставляет конкретная версия Android и системная звонилка.
